# local-rag-agent

Локальный агент для вопросов на естественном языке по личному архиву исследовательских файлов: код Python (`.py`), Jupyter-ноутбуки (`.ipynb`), PDF и изображения (`.png`). Ответы содержат ссылки на источник: файл и строки, ячейку ноутбука, страницу. Всё работает на локальной машине. Данные корпуса, индексы и трассы в сеть не уходят.

## Требования

- Python 3.11+ и PyTorch. Подходит сборка под ROCm (AMD), CUDA (NVIDIA) или CPU. Проверено на RX 7900 XTX: Windows 11, ROCm 7.2, torch 2.9.
- [Ollama](https://ollama.com) и LLM, по умолчанию `qwen3.5:9b`:
  ```bash
  ollama pull qwen3.5:9b
  ```
- Эмбеддер [BAAI/bge-m3](https://huggingface.co/BAAI/bge-m3), около 2.3 ГБ, скачивается с Hugging Face:
  ```bash
  hf download BAAI/bge-m3 --exclude "onnx/*"
  ```

## Установка

```bash
pip install -e ".[dev]"
```

Если зависимости уже стоят (например, в conda-окружении с ROCm-сборкой torch), ставьте только сам пакет. Так pip не тронет torch:

```bash
pip install -e . --no-deps
```

## Быстрый старт

Демо одной командой. Команда соберёт `demo_corpus/`, если его нет, запустит API, проиндексирует корпус и откроет UI:

```bash
make demo          # или: python -m rag_agent.cli demo
```

Запуск по частям:

```bash
rag serve                                  # API на 127.0.0.1:8765
rag ui                                     # интерфейс Streamlit на :8501
```

В интерфейсе выберите рабочую папку, при необходимости поправьте исключения и нажмите «Индексировать». Повторная индексация инкрементальная: разбираются только новые и изменённые файлы, удалённые убираются из индекса.

CLI без UI:

```bash
rag index "C:\path\to\WorkSpace" -x "Аккаунты"
rag ask "Какой learning rate использовался в эксперименте с аугментациями?"
rag status
```

## Как устроено

```
файлы ─► walker (исключения) ─► парсеры .py / .ipynb ─► узлы + связи
        ─► BGE-M3 (dense + sparse) ─► Qdrant      ┐
        ─► SQLite-каталог (files, nodes, edges)   ┴─► поиск ─► LLM (JSON: answerable, answer [n]) ─► ответ с цитатами
```

- **Единая модель данных** (`schema.py`). Файл разбирается на узлы: фрагмент кода, markdown-ячейка, ячейка кода, вывод ячейки и т. д. Между узлами хранятся типизированные связи: `contains`, `produces` (ячейка → её вывод) и другие.
- **Ноутбуки.** Каждая ячейка становится отдельным узлом. Вывод ячейки — тоже отдельный узел. Он обрезается с сохранением хвоста, где обычно стоят итоговые метрики, и индексируется вместе с кодом, который его породил.
- **Код `.py`.** В Э1 режется на окна по строкам с перекрытием, это бейзлайн для гипотезы H1. AST-чанкинг появится в Э3.
- **Индексы.** Для каждой комбинации «папка × эмбеддер × настройки чанкинга» создаётся отдельный индекс. Поэтому абляции переключаются без переиндексации ранее построенных вариантов.
- **Ответ.** Генерация идёт со structured output: JSON-схема, декодирование ограничено сервером. Ссылки `[n]`, не соответствующие найденным фрагментам, удаляются. Если ответа в найденном нет, модель должна отказаться.

```
src/rag_agent/
  config.py        настройки: configs/default.yaml < configs/local.yaml < RAG__SECTION__KEY
  schema.py        узлы, связи, локации
  ingest/          обход папки и парсеры
  index/           эмбеддер, Qdrant, SQLite-каталог, инкрементальный индексатор
  retrieval.py     dense / sparse / hybrid (RRF)
  generation.py    промпт, JSON-ответ, разбор цитат
  llm.py           Ollama или любой OpenAI-совместимый API
  engine.py        общее ядро для API и CLI
  api.py, ui.py, cli.py
scripts/build_demo_corpus.py   генерация публичного демо-корпуса
demo_corpus/                   сгенерированный корпус (sklearn-датасеты, выполненные ноутбуки)
```

## Конфигурация

Все параметры задаются в `configs/default.yaml`. Для машинно-специфичных настроек создайте `configs/local.yaml`, он не коммитится. Любой ключ можно переопределить переменной окружения, например `RAG__LLM__MODEL=qwen3.6:27b` или `RAG__RETRIEVAL__MODE=hybrid`.

## Приватность

- Индексы, каталоги и трассы хранятся в `~/.local-rag-agent`, вне репозитория.
- Собственный репозиторий и каталог данных никогда не индексируются, даже если лежат внутри выбранной папки.
- Папки с чувствительными данными добавляйте в исключения. По умолчанию уже исключены `Аккаунты`, а также `.git`, окружения и все скрытые папки.
- Содержимое файлов подаётся модели как данные. Промпт запрещает выполнять инструкции из фрагментов.
- Телеметрия Streamlit отключена в `rag ui`.

## Разработка

```bash
python -m pytest -q
```

Тесты используют поддельные эмбеддер и LLM. Им не нужны GPU, модели и приватные данные, поэтому они идут в CI.
