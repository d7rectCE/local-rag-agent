# Опасный код в песочнице

Образ `rag-sandbox:py312`, лимиты: память 2g, CPU 2.0, процессов 256, таймаут 30 с. Корпус — временная копия демо-корпуса, смонтированная только для чтения; после прогона не изменилась.

Заблокировано: **12 из 12**.

| network-dns | разрешить имя через DNS | `--network none` | да | 1 |
